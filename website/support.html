A little guidance

Help with your report.

How do I import a report?

  1. Open Settings → Privacy & Security → App Privacy Report on your iPhone or iPad.
  2. Enable the report if needed and allow it to record activity. Turning it on does not create a complete history immediately.
  3. Use the export/share action to save the report to Files.
  4. Open Fire Privacy, choose import, and select that exported report.

Screen labels and report availability vary with the operating system. Use the in-app synthetic demo if you do not have a report yet.

Why does a report look empty or incomplete?

The report contains only the activity and record types available in the selected file. A newly enabled report may have little history. Unsupported or malformed records are not evidence that nothing happened. Check the import result, export a new report from Settings, and try again.

Does a domain contact mean something is unsafe?

No. A contact is a recorded event. It does not establish what information was sent, the owner’s intent, or a security finding. Fire Privacy is a local report viewer; it does not block requests, run a VPN, or change other apps’ permissions.

How do export and delete work?

Export uses the system share sheet to share a readable normalized JSON report. Only share it with someone you trust. Delete removes the app’s stored report, temporary exports, and encryption key. It leaves your original file, history in Settings, and previously shared copies in their original locations.

Contact the project

For ordinary help, an import bug, or a privacy-policy question, open a project issue on GitHub. Include the app version, iOS/iPadOS version, what you expected, and what happened. The project issue tracker requires a GitHub account to post.

Issues are public. Do not attach a real App Privacy Report or a screenshot containing personal activity. A small synthetic example is enough. Do not post credentials, private keys, account identifiers, or a sensitive vulnerability reproducer. Ask for an appropriate private reporting channel before disclosing sensitive details.

The privacy policy explains the app’s local data handling. GitHub handles information you voluntarily post to the issue tracker under its own policies.
