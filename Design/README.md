# Fire-inspired UI proposal

`FirePrivacy-concept.png` is an AI-generated design concept for user review,
not a screenshot from a compiled app. It proposes warm charcoal surfaces,
ember-orange and gold accents, flame branding, and an adaptive iPad sidebar.
The displayed numbers and icons are illustrative sample data.

The implemented native app currently uses the earlier navy/teal palette.
Apply the approved fire visual direction in SwiftUI after the user reviews
this concept. Keep exported bundle identifiers honest, sensor totals labeled
as event records, Dynamic Type and VoiceOver intact, and imported strings plain
text. App icons must not imply that fictional identifiers were resolved to
installed apps.

Only actual native-build captures belong in the App Store screenshot set.
