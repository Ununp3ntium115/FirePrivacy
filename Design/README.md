# Approved fire-inspired design

`FirePrivacy-concept.png` is an AI-generated design concept approved by the
owner on October 5, 2026, not a screenshot from a compiled app. It uses warm charcoal surfaces,
ember-orange and gold accents, flame branding, and an adaptive iPad sidebar.
The displayed numbers and icons are illustrative sample data.

The native SwiftUI app now applies the charcoal, ember, and gold palette,
static glow, flame branding, and adaptive iPad sidebar. Its figures come from
the loaded report; sample data stays explicitly labeled. Exported bundle
identifiers remain literal, sensor totals are labeled as event records, and
Dynamic Type, VoiceOver, and plain-text imported strings remain supported.
Generic app symbols do not imply installed-app identification.

`FirePrivacy-icon-master.png` is the original generated flame artwork.
`scripts/generate-app-icon.py` prepares the opaque 1024-pixel universal iOS
asset using ImageMagick or macOS `sips`. It does not generate new artwork.

Only actual native-build captures belong in the App Store screenshot set.
